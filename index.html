HOW IT WORKS

Waiver rules

The Draft waiver queue can change after successful claims, so overall league rank alone does not reveal the current waiver priority. The estimated standings-based order updates automatically when all Gameweek scores are loaded. It is not the official claim-processing order; use official league priority to determine actual waivers.

LEAGUE ACTIVITY

Confirmed squad changes

Only players actually added to or removed from a manager’s squad between two recorded Gameweeks appear here. Unsuccessful waiver requests are excluded.

Changes are confirmed from successive Draft Gameweek rosters after the later deadline has passed. The exact transaction mechanism (waiver, free-agent signing, or trade) is not assumed; individual add/drop pairings are shown only where unambiguous.
