Touchline 4.1 — Full-squad Trade Analyzer

Changes:
- Trade Analyzer now lets each manager select 1–15 players (formerly max 3).
- Keeps equal player counts and matching positional composition.
- Maintains multi-factor composite value and Free Agent data loading from v4.0.
- /api/version returns 4.1 after deploying server.py.

Installation:
1. Extract the ZIP.
2. Upload files into the ROOT of the existing Touchline GitHub repository, replacing matching files.
3. Redeploy on Render.
4. Hard refresh the website, check /api/version = 4.1 and Trade Analyzer label v4.1.

This is a comparison tool; no real transactions are sent.
